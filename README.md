# mechanical-engineering-portfolio

> A documented journey from complete beginner to aspiring Mechanical Engineer.

## About Me
Hello! I'm **Heamakesh Bajina**, a Cambridge International A Level student from India with a strong interest in **Mechanical Engineering** and a long-term goal of specializing in **Aerospace Engineering**.

This repository documents my engineering learning journey through CAD design, electronics, Arduino programming, and engineering documentation. Rather than simply listing skills, I am using this portfolio to demonstrate my progress through completed projects, design iterations, and technical reflections.
