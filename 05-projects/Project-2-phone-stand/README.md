# Project 02 – Engineering Phone Stand

## Objective

Design and model a functional phone stand capable of securely supporting a smartphone while applying engineering design principles and CAD fundamentals learned in previous lessons.

---

## Project Overview

This project involved designing a simple yet functional phone stand that supports a smartphone in portrait orientation. The design emphasizes structural stability, ease of manufacturing, and efficient use of material.

---

## Design Features

- Stable base
- Angled support structure
- Front retaining lip
- Minimal material usage
- 3D printable geometry
- Clean and simple design

---

## CAD Tools Used

- Basic Shapes
- Align
- Group
- Hole
- Ruler
- Snap Grid
- Duplicate

---

## Engineering Concepts Applied

- Structural Stability
- Center of Gravity
- Support Angle
- Load Distribution
- Material Efficiency
- Functional Product Design
- Design for Manufacturing (DFM)

---

## Design Process

1. Created the base platform.
2. Designed an angled back support.
3. Added a front lip to prevent the phone from sliding.
4. Used alignment tools to ensure symmetry.
5. Checked dimensions using the Ruler tool.
6. Evaluated the design for stability.

---

## Challenges

- Selecting an appropriate support angle.
- Maintaining stability while minimizing material.
- Aligning the support with the base.

---

## Solutions

- Increased support angle until the phone remained stable.
- Used the Align tool for accurate positioning.
- Kept the design simple to improve manufacturability.

---

## Future Improvements

- Increase base length for additional stability.
- Add rounded edges.
- Include a charging cable cut-out.
- Reduce material using triangular cut-outs.
- Design a foldable version.
