# Project 04 — Spur Gear Pair

## Overview

This project involved designing a pair of spur gears in Tinkercad using the parametric Useful Gear shape generator.

The objective was to understand basic gear geometry, tooth count, center bores, gear ratios, and positioning of two gears intended to mesh.

This was the first project in the portfolio focused specifically on mechanical power transmission concepts.

---

## Objective

- Learn the basic structure of a spur gear
- Understand gear tooth count
- Understand bore diameter
- Understand pitch as a gear-generator parameter
- Create two gears with different tooth counts
- Position two gears so their teeth visually mesh
- Calculate the theoretical gear ratio
- Practice precise CAD positioning and measurement

## Engineering Concepts

### Spur Gear

A spur gear is a cylindrical gear with straight teeth that transmit rotational motion between parallel shafts.

### Bore Diameter

The bore is the central hole of the gear.

For both gears:

**Bore diameter = 6 mm**

The bore provides space for a shaft or axle.

### Tooth Count

The number of teeth affects the rotational relationship between two meshing gears.

Gear A:

**20 teeth**

Gear B:

**40 teeth**

---

## Gear Ratio

The theoretical gear ratio can be calculated from the number of teeth:

Gear ratio = Driven gear teeth / Driver gear teeth

= 40 / 20

= **2:1**

Therefore, if the 20-tooth gear is the driver, the 40-tooth gear theoretically rotates at half the angular speed of the driver.

This relationship also means the driven gear has approximately twice the torque in an idealized system, ignoring losses.

## Design Process

1. Opened Tinkercad 3D Design.
2. Added the Useful Gear / Spur Gear shape generator.
3. Created the first gear with 20 teeth.
4. Set the pitch to 2.
5. Set the gear height to 5 mm.
6. Set the bore diameter to 6 mm.
7. Set slop to 0.01.
8. Duplicated the gear.
9. Changed the duplicated gear to 40 teeth.
10. Kept the remaining parameters consistent.
11. Positioned both gears on the same horizontal centerline.
12. Used the Ruler in midpoint mode to measure the distance between the gear centers.
13. Recorded a center-to-center distance of 38 mm.
14. Positioned the gears so their teeth visually meet.

---

## Design Decisions

### Different Tooth Counts

A 20-tooth and 40-tooth gear were selected to create a simple 2:1 theoretical gear ratio.

### Equal Thickness

Both gears were designed with a 5 mm height to maintain a consistent thickness.

### Equal Bore

Both gears use a 6 mm bore so they could theoretically use compatible shafts or axles.

### Parametric Design

The Tinkercad gear generator was used instead of manually creating individual teeth.

This allowed the number of teeth and other gear parameters to be changed efficiently.

## Limitations

This project is a CAD representation of a gear pair.

The gears were visually positioned to mesh, but the project did not include:

- Physical 3D printing
- Shaft installation
- Bearing installation
- Load testing
- Torque measurement
- Real mechanical motion testing
- CAD motion simulation

Therefore, the 2:1 gear ratio represents the theoretical relationship based on tooth count.
