# Project 01 – Engineering Name Tag

## Objective

Design a professional name tag using the CAD tools learned in the foundational Tinkercad lessons.

---

## Features

- Rounded rectangular base
- Engraved name
- Hanging hole for a keychain or lanyard
- Decorative geometric element
- Symmetrical layout

---

## CAD Tools Used

- Basic Shapes
- Text
- Ruler
- Align
- Group
- Hole
- Duplicate
- Snap Grid

---

## Engineering Concepts

- Dimensional accuracy
- Object alignment
- Material removal using hole shapes
- Symmetry
- Design aesthetics
- Basic manufacturability

---

## Challenges

- Positioning the text and hanging hole accurately.
- Aligning all elements while maintaining a balanced layout.

---

## Reflection

This project helped me apply the fundamental CAD tools learned in previous lessons to create a complete design. I practiced accurate positioning, alignment, and grouping while considering both functionality and appearance.

---

## Skills Demonstrated

- Precision CAD modeling
- Engineering documentation
- Design planning
- Object manipulation
- Basic product design
