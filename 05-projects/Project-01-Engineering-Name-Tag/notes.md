## Project Goal

Design a professional engineering name tag using the CAD skills learned in the first four Tinkercad lessons.

---

## Tools Used

- Basic Shapes
- Text Tool
- Ruler Tool
- Align Tool
- Group
- Hole
- Duplicate
- Snap Grid

---

## Design Features

- Rounded rectangular base
- Engraved name
- Hanging hole for a keychain or lanyard
- Decorative geometric star
- Symmetrical layout

---

## What I Learned

- How to combine multiple shapes into a complete design.
- How to align objects accurately using the Align tool.
- How to use hole shapes to create functional cut-outs.
- How to position text neatly and maintain a balanced layout.
- How to apply precise measurements using the Ruler tool.

---

## Challenges Faced

- Positioning the text evenly within the name tag.
- Aligning the hanging hole with the center of the design.
- Balancing the decorative element without affecting readability.

---

## How I Solved Them

- Used the Align tool to center objects.
- Used the Ruler tool to check positioning.
- Adjusted the size and placement of the decorative elements until the layout looked balanced.

---

## Improvements for the Future

- Add more advanced design details such as beveled edges.
- Experiment with raised text instead of engraved text.
- Improve spacing between the hanging hole and the text.
- Explore different fonts and decorative elements while maintaining readability.
