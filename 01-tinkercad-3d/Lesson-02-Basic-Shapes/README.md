# Lesson 02 – Basic Shapes & Object Manipulation

## Objective

The objective of this lesson was to become familiar with the fundamental 3D shapes available in Tinkercad and learn how to manipulate them accurately using basic CAD tools.

---

## Learning Outcomes

By completing this lesson, I learned how to:

- Insert basic 3D shapes into the workplane
- Move objects freely in 3D space
- Resize objects using exact dimensions
- Rotate objects along different axes
- Duplicate objects efficiently
- Arrange objects with consistent spacing
- Understand basic object positioning

---

## Engineering Concepts Learned

- Cartesian Coordinate System (X, Y, Z)
- Object Dimensions
- Scaling
- Rotation
- Symmetry
- Spatial Awareness
- Precision in CAD Design

---

## Exercises Completed

- Added multiple basic shapes
- Resized a cube to specific dimensions
- Resized a cylinder
- Rotated objects by different angles
- Arranged shapes neatly
- Duplicated objects into a straight row

---

## Skills Developed

- Basic CAD navigation
- Shape manipulation
- Dimension control
- Rotation
- Duplication
- Workspace organization

---

## Reflection

This lesson introduced the core tools required to manipulate objects in Tinkercad. I became comfortable resizing, rotating, moving, and duplicating shapes, which are essential skills for creating accurate mechanical models.
