# Lesson 04 – Precision Engineering

## Objective

The objective of this lesson was to learn how to create accurate CAD models using engineering precision rather than estimating dimensions visually.

---

## Learning Outcomes

By completing this lesson, I learned how to:

- Use the Ruler tool for precise measurements
- Modify object dimensions accurately
- Position objects using exact coordinates
- Adjust the Snap Grid for different levels of precision
- Use the Workplane tool to build on different surfaces
- Apply Duplicate & Repeat to efficiently create repeated features

---

## Engineering Concepts Learned

- Engineering Precision
- Dimensional Accuracy
- Cartesian Coordinate System (X, Y, Z)
- Parametric Positioning
- Manufacturing Tolerances (Introduction)
- Repetitive Design

---

## Exercises Completed

- Used the Ruler tool
- Changed Snap Grid settings
- Positioned objects using exact coordinates
- Built objects using the Workplane tool
- Practiced Duplicate & Repeat
- Created a precision block with four identical cylinders

---

## Skills Developed

- Precision CAD Modeling
- Measurement
- Accurate Positioning
- Efficient Modeling Techniques
- Engineering Workflow

---

## Reflection

This lesson reinforced the importance of precision in engineering design. Instead of placing objects by eye, I learned how to use measurement tools and positioning techniques to create accurate models. These skills are fundamental for designing mechanical components that fit and function correctly.
