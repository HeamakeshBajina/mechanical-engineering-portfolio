# Lesson 01 — Tinkercad Interface and Navigation

## Objective

Become familiar with the Tinkercad workspace and learn the fundamental navigation controls used in CAD software.

---

## Learning Outcomes

By the end of this lesson, I was able to:

* Navigate the Tinkercad workspace
* Understand the purpose of the workplane
* Use the ViewCube to inspect models from different perspectives
* Orbit, pan, and zoom around a model
* Reset the camera using the Home view
* Place simple objects onto the workplane

---

## Engineering Concepts

This lesson introduced several core CAD concepts:

* **Workplane** – The reference plane where models are created.
* **3D Coordinate System** – Objects exist in X, Y, and Z dimensions.
* **Camera Navigation** – Efficient inspection of models from multiple angles.
* **Spatial Awareness** – Understanding how an object appears from different viewpoints.

These concepts form the foundation for all future CAD work.
